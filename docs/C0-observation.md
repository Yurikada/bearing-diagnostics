### 検出した矛盾: サンプリング周波数

Readme は「sampling rate 20 kHz」と「1秒スナップショット = 20,480点」を併記しており
両立しない(20kHz × 1s = 20,000点)。実効 fs が 20.00k / 20.48k のどちらかで周波数軸が
**2.4%** 系統的にずれる — すべり(1〜2%)より大きい。

- Decision(2026-07-26 **合意済み**): fs = **20.48 kHz** を採用。
  根拠: 「20,480点・1秒」の方が精密な記述で「20kHz」は丸めと読める。
  ±2.4% は照合窓に含め、C4 でスペクトル線位置が判別証拠になるかは**事前宣言の上で**確認する。

## 2. 幾何と故障特徴周波数の宣言

### 式(導出は無滑り転がり接触の運動学から)

$$
\mathrm{FTF} = \frac{f_r}{2}\left(1 - \frac{d}{D}\cos\varphi\right), \qquad
\mathrm{BPFO} = Z \cdot \mathrm{FTF}, \qquad
\mathrm{BPFI} = Z\,(f_r - \mathrm{FTF})
$$

$$
\mathrm{BSF} = \frac{D}{2d}\left(1 - \left(\frac{d}{D}\cos\varphi\right)^2\right) f_r
$$

検算則: $\mathrm{BPFO} + \mathrm{BPFI} = Z f_r$ / $\mathrm{FTF} < f_r/2$ / $\mathrm{BSF} < (D/2d) f_r$。
転動体傷の**打撃**周波数は自転1回転で内輪・外輪に1回ずつ接触するため $2 \times \mathrm{BSF}$。

### CWRU 駆動側 SKF 6205-2RS JEM(深溝玉、φ=0)

幾何: Z=9、d=0.3126 in、D=1.537 in。**本人が幾何から計算し、公式公表値と照合済み**(軸回転数の倍率):

| 量 | 本人計算 | CWRU公表 | 判定 |
|---|---|---|---|
| FTF | 0.398 | 0.39828 | 一致 |
| BPFO | 3.585 | 3.5848 | 一致 |
| BPFI | 5.415 | 5.4152 | 一致 |
| BSF | 2.357 | 4.7135 | **規約差**: 公表値は打撃周波数 = 2×BSF |

### 参照教材の誤植2件(検出過程の記録)

計算過程で参照した振動診断教材(公開技術講座資料)の式に誤植を発見:

1. BPFI の $(1 + \frac{d}{D}\cos\alpha)$ の「+」が「・」に化けている
2. BSF の係数が $f_r$ ではなく $f_o$(外輪通過周波数)になっている — 玉の自転は
   玉数 Z に依存し得ないため物理的に不可能。誤答 8.448 がこの式を忠実に適用した値と
   一致し、出所を特定できた

検出に効いた検算則は上記3本。**教科書・公式集も突き合わせの対象**(scheme.md 参照)。

### IMS Rexnord ZA-2115(複列ころ、1列あたりで計算)

幾何(Readme に記載なし。Qiu et al. 2006 / Bechhoefer 解析文書から):
Z=16(1列)、d=0.331 in、D=2.815 in、φ=15.17°、軸 2000 rpm( $f_r = 33.33$ Hz)。

**宣言値(2026-07-26 本人計算、検算 BPFO+BPFI = 533.3 = Z·fr 通過)**:

| 量 | 宣言値 [Hz] |
|---|---|
| FTF | 14.77 |
| BPFO | 236.4 |
| BPFI | 296.9 |
| BSF(自転) | 139.9(打撃は 2× = 279.8) |

計算過程の記録: BSF の初回誤答 992 Hz は教材誤植式( $f_o$ 基準)の再適用によるもの
(4.198 × 236.4)。CWRU 側の誤答 8.448 と完全に同型で、**誤植の発見と正式の定着は別**
であることの実例。上界検算 $\mathrm{BSF} < (D/2d) f_r \approx 142$ Hz で検出。

## 3. 観測設計の帰結(C1以降への引き継ぎ)

- Δf = 1/T = 1 Hz(1秒スナップショット)。BPFO/BPFI の分離には十分だが、
  窓関数の主葉幅・回転数変動のにじみ・すべり(±1〜2%)・側帯波( $\pm f_r$ )が実効を落とす
- 欠陥衝撃のエネルギーは特徴周波数の線ではなく**変調された構造共振帯**(数kHz)に乗る
  → 生スペクトルでなくエンベロープ解析(C3)が要る理由
- 照合は「計算値ピッタリ」ではなく **±数%の窓**で行い、窓は事前に宣言する

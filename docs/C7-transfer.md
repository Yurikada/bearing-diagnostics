# C7 — 転移テスト: Set1(独立 run)への同一パイプライン適用

対象コード: `src/c7_set1.py` / `src/c7_analyze.py`

## 1. 目的と条件

Set2 で開発した検出器(エンベロープ線/床・FLI-v2・max-channel)を、**開発に使っていない
独立 run** で検証する。Set1 は同じリグ・同じ軸受だが条件が3つ厳しい:
34.5日・2,156ファイル / 8ch(各軸受 x/y) / **B3内輪 + B4転動体の2故障同時進行**。

事前の予想(測る前に記録):
- B3: BPFI 296.9 Hz の主線 + ±33.33 Hz 側帯が明瞭に立つ(高確度)
- B4: 2×BSF 279.8 Hz ± FTF 14.77 Hz。**検出確度 20〜30%**(CWRU 玉欠陥の経験から)
- 帰属: 2故障同時では従来 max-channel が破綻 → **周波数分離型**(窓ごとに ch 間比較)を設計

## 2. 検分と設計

- **Readme との食い違い第4号**: 5分間隔ファイルは実測148個(公称は「最初の43個」。
  先頭43個の記述自体は正しいが、再開直後にも5分間隔区間が複数ある)。
- **ギャップ24箇所**(>30分、最大6.2日)。連続判定(3点連続・ロック)はギャップで切る。
- **ベースライン(本人設計の二段構え)**: ギャップ前(day 0〜0.93)と再開後(7.1〜7.5)の
  RMS 中央値比が全8chで 1.04〜1.24(規則: 1.5倍以内)→ 同等と判定し、
  **day 7.11〜8.64 の100ファイル**を採用。
- しきい値は q99.9(C5 推奨)と kσ を併記。ただし n=100 の q99.9 は実質最大値であり
  脆弱(C5 の警告がそのまま該当することを認識した上で使用)。

## 3. 時間領域(転移した原理)

- 順序は **尖度が先行**(B4: day 28、B3: day 31.5)→ RMS(day 33.5〜) — **Set2 と逆順**。
- ただし矛盾ではない: Set1 の RMS ベースラインはギャップ・再起動の段差で変動が大きく、
  Set2 の CV 1.4% という静けさが成立しない。**「感度 = 物理 × ベースライン変動」という
  同一の原理が、2つの run の逆の順序を両方とも説明する**(本人の言語化)。
- 最終盤の B3 は尖度が数十 → 3〜8 へ崩落しながら RMS が 0.58 g へ急増 —
  C1 で述べた**ガウス化(剥離の全面化)を初めて完全な形で観測**(Set2 は全面破壊前に終了)。

## 4. エンベロープ(転移しなかったもの・したもの)

| 測定 | 結果 |
|---|---|
| B3窓 線/床(ch5, 故障期) | 中央値 **1.42**(Set2 の B1 は 10〜30 — 1桁以上弱い) |
| B4窓 線/床(ch7) | 中央値 1.4〜2.0、最大 6.1 |
| B3窓ピーク位置(故障期) | **301 Hz にロック**(回顧帯域 ch5: 176/207点)。予測 296.9 |
| B4窓ピーク位置 | **278〜279**(2×BSF −0.3〜−0.6%)に一貫した最頻値 |
| 側帯(BPFI±fr / 2×BSF±FTF) | 検査エポックでは**すべて床レベル** |
| 周波数分離型帰属 | B4窓: 自ch勝率 **73%** / B3窓: **35%**(最多勝者は ch7) |
| 健全 ch1〜4 の誤報 | 早期 0(Set2 から再現)、後期 2(伝播) |

### 予想の対称反転

高確度と宣言した B3(BPFI)が**全敗**し、確度 20〜30% と見積もった B4(2×BSF)が
**位置指紋を形成**した。事前確度と実測が反転した事実自体を記録する。

### 301 Hz 問題(設計の穴と判定不能)

- 窓衝突チェックは B3/B4 の線族のみを見ており、**回転高調波を見ていなかった**:
  9×fr = 300.0 Hz が BPFI 窓(291〜303)の内側にいる。
  **教訓(本人)**: 窓の分離性検証には k·fr の整数高調波族を必須の干渉源として含める。
- 本人設計の判別測定(fr を低次高調波の放物線補間で実測 → 9fr′ vs 8.9075fr′ の
  3 Hz 分離で判定)を2回実行(ファイル毎・40ファイル平均)。結果: fr 線族の S/N が低く
  推定ばらつき ±0.5 Hz → 9fr′ の誤差幅 ±4.5 Hz が残差 +3.9 Hz を覆い、判別不能。
  BPFI 説は fr 実測(≈33.0 Hz)と不整合で不利だが、第三源も排除できない。
- **確定判定(本人)**: 「301 Hz ピークの起源同定は判定不能とする」。
  付随する教訓: **判別測定にも成立条件(アンカー線の S/N)がある**。

### B3 の BPFI 線が育たない理由(仮説・未検証)

1. 内輪欠陥はエネルギーが ±k·fr 側帯群と高調波に分散し(C3 で側帯/主線 36% を実測)、
   終盤は面荒れの広帯域化が床を持ち上げ、線/床比の分母が膨らむ。
2. 因果帯域スキャンは「最も衝撃的な帯域」を追うため、2故障源の同居下では
   B4 の帯域を掴み、B3 の変調構造が薄い帯域で包絡線を取った可能性。
3. センサ受振軸(x/y)と荷重域方向のミスマッチ。

## 5. 転移テストの結論

- **転移した**: 時間領域の感度原理(逆順まで含めて説明) / B4 の周波数指紋(278〜279) /
  健全chの早期誤報ゼロ / ギャップ・床規則などの運用規則。
- **転移しなかった**: B3(主故障)のエンベロープ主線検出 / B3窓の帰属(35%) /
  n=100 での q99.9 安定性。
- Set2 の検出器は「そのまま」は独立 run に転移しない。壊れた箇所はいずれも
  事前に本人が指摘していた弱点(2故障同時・分位点の脆弱性・帯域スキャンの前提)が
  現実化したものであり、**弱点予測の的中こそが転移テストの成果**。
